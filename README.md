# ecommerceanalysis
Ecommerce analysis
This project aimed to analyze customer satisfaction in relation to demographic factors and purchasing behavior, with the goal of uncovering insights to enhance marketing strategies. By examining features such as Age and Purchase_Category, we built a predictive model to estimate customer satisfaction. The model's performance, however, showed limited effectiveness, as the R-squared value was negative, indicating that the selected features alone didn't strongly predict satisfaction. Despite this, the findings suggest that targeting different age groups or customer segments based on their purchasing behavior could still offer valuable marketing opportunities. Future steps involve refining the model with additional features or more advanced algorithms to better understand customer preferences and improve marketing efforts.
